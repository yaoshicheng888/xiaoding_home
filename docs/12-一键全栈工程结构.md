## 三、启动方式（核心）

### 1. 安装依赖

```bash id="install"
cd backend
npm install

cd ../frontend
npm install

cd ../admin
npm install
```

---

### 2. 启动后端

```bash id="backend_run"
cd backend
npm run start:dev
```

---

### 3. 启动前端（用户端）

```bash id="frontend_run"
cd frontend
npm run dev:weapp
```

---

### 4. 启动后台

```bash id="admin_run"
cd admin
npm run dev
```

---
