## 三、核心模块说明

---

### 1. user模块

负责：

* 用户注册
* 用户登录
* 用户信息

接口：

* POST /user/login
* GET /user/info

---

### 2. provider模块（师傅）

负责：

* 师傅登录
* 技能标签
* 接单能力

接口：

* POST /provider/login
* GET /provider/list

---

### 3. order模块（核心）

负责：

* 创建订单
* 状态流转
* 查询订单

接口：

* POST /order/create
* GET /order/list
* GET /order/detail

---

### 4. ai模块（关键）

负责：

👉 用户文本解析

流程：

用户输入 → AI → 返回结构化数据

接口：

* POST /ai/parse

---

### 5. dispatch模块（派单核心）

负责：

* 自动派单
* 手动派单
* 抢单逻辑

接口：

* POST /dispatch/auto
* POST /dispatch/manual

---

### 6. payment模块

负责：

* 创建支付
* 回调处理
* 资金记录

接口：

* POST /pay/create
* POST /pay/callback

---

### 7. admin模块（后台）

负责：

* 订单管理
* 师傅管理
* 财务管理
* 风控管理

---

## 四、核心业务流程（非常重要）

```text id="flow1"
用户输入
 → AI解析
 → 创建request
 → 创建order
 → dispatch派单
 → provider接单
 → 完成服务
 → payment结算
```

## 五、Prisma核心模型（简化）

```prisma id="prisma1"
model User {
  id    Int @id @default(autoincrement())
  phone String
  name  String?
}

model Provider {
  id    Int @id @default(autoincrement())
  name  String
  phone String
  skill_tags String
}

model Order {
  id         Int @id @default(autoincrement())
  user_id    Int
  provider_id Int?
  status     String
  price      Float
}
```

## 六、核心设计原则

### 1. 模块化

每个业务独立模块

### 2. 订单为中心

所有系统围绕 order

### 3. AI只做解析

不参与业务决策

### 4. 派单独立

dispatch模块单独控制逻辑
