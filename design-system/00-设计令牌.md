# 小钉到家 V3

# 00｜设计令牌（Design Token）

Version：3.0

更新时间：2026

---

# 一、目的

Design Token 是整个小钉到家唯一视觉标准。

包括：

- 用户端
- 师傅端
- 后台
- 官网
- H5
- 小程序
- 后续所有业务

任何页面不得自行定义颜色、字号、圆角、阴影。

所有设计必须引用 Token。

---

# 二、设计理念

设计不是为了漂亮。

而是为了：

降低学习成本。

提高下单速度。

建立用户信任。

提高维修效率。

提高运营效率。
